IndexedDB: calculando...

Somente nesta tela ficam disponíveis as ações de importação, exportação, limpeza de lançamentos e restauração da base de demonstração.

Salvar dados — grava manualmente a base atual antes de fechar, exportar ou transferir o sistema.
Importar JSON — substitui todos os dados atuais pelo arquivo importado.
Mesclar JSON — une os dados do arquivo com os dados atuais, sem apagar lançamentos existentes. Ideal para consolidar registros de diferentes servidores.

Fluxo operacional

  1. Cadastros — veículos (com tipo gerenciável), motoristas, setores e combustíveis.
  2. Abastecimentos — lançamento com validação de KM, autorização e valor automático. Comprovantes (PDF/imagem) vinculados a cada registro via IndexedDB.
  3. Consulta avançada — filtros por período, setor, veículo, motorista, placa e texto livre. Exportação CSV e impressão.
  4. Dashboard — 5 cards de KPIs clicáveis, últimos abastecimentos, consumo por placa com gráfico, média R$/L em tempo real.
  5. Gráficos comparativos — comparativo de VTRs por mês/ano com barras, linhas, área e empilhado. Sub-gráficos de pizza, ranking e preço clicáveis.
  6. Troca de óleo — registro com tipo de óleo, litros e custo. Cards de status com alertas visuais pulsantes. Gráfico de consumo de óleo.
  7. Import/Export JSON — exportação completa com comprovantes em base64. Importação com substituição ou mesclagem de dados de múltiplos operadores.
  8. Armazenamento — IndexedDB (~50% do disco livre). Migração automática do localStorage.

Estrutura prevista de produção

  • Front-end web responsivo
  • API REST com autenticação
  • Banco PostgreSQL ou MySQL
  • Auditoria de inclusão, edição e exclusão
  • Perfis: administrador, operador, consulta
